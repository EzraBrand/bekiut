# Presentation options

## 1. Searchable table + expandable notes (recommended)

**Best for:** comparing resources by category, scholarly use, provenance and link status.

Keep the first view selective, with original footnote/reference links available through an explicit historical-inventory switch. Long annotations belong in expandable details. Avoid a wide spreadsheet on phones: turn rows into labeled blocks.

**Implemented:** table and card views share one dataset; category, origin and status filters; text search; provenance details; CSV downloads.

## 2. Task-oriented research pathways

**Best for:** readers who know their question but not the relevant resource.

Possible pathways: “Find a passage,” “Compare manuscript witnesses,” “Locate secondary literature,” “Decode an abbreviation,” and “Check an AI-generated citation.” Each should use a small worked example, then link into the directory.

**Tradeoff:** needs editorial examples and regular testing rather than just a directory update. Not implemented in this first edition.

## 3. Narrative handbook + printable PDF

**Best for:** teaching, citation and offline reading.

Retain short introductions and critical annotations from the original, but generate dated tables from the same data. Keep the archived 2023 text clearly separate from the 2026 editorial text.

**Tradeoff:** manually maintaining both a long PDF and web table risks drift. Prefer generating a future PDF from the shared data and revised prose. A redesigned 47-page PDF is not produced in this pass.

## Recommendation

Use the searchable directory as the GitHub Pages home, with a concise AI chapter and transparent audit. Add research pathways after editorial review. The plain JSON/CSV dataset can later be imported into Bekiut without coupling the current project to its application code.
