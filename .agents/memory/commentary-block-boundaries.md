---
name: Commentary block boundaries
description: Why Bavli commentary blocks follow clause links rather than whole unbolded runs.
---
Evaluate punctuation-linked commentary as a unit, not an entire consecutive run of unbolded text.

**Why:** A quoted verse continuation and an independent explanation can be adjacent and both unbolded. Treating the whole run as one block would either move part of the translation or unnecessarily retain the explanation. The user's Berakhot 3b example requires keeping the verse continuation while moving the subsequent “Taken together” explanation.

**How to apply:** When revising eligibility, preserve the distinction between a continuation attached to translation and a new, complete explanatory sentence. Keep the Berakhot question and semicolon-linked examples compatible with that distinction.
