name: Reader note typography
description: Shared readability policy for Bavli, Yerushalmi, and Rambam footnotes
---

For Bavli and Yerushalmi, footnote bodies must match the main English text size exactly at every reader setting. Other readers retain their shared readable-minimum note policy unless requested otherwise.

**Why:** The user explicitly replaced the earlier Bavli minimum-size policy with exact parity with main English text, then requested the same behavior for Yerushalmi. Applying relative English scaling inside a separately sized note container compounds or overrides the intended size.

**How to apply:** Bavli and Yerushalmi notes should inherit the same base as main English and apply English text scaling once. Preserve English font preferences and interactive reference hit areas. Do not extend this change to Rambam without a request.
